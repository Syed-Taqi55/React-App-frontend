# Task manager

A local task manager built with React and Vite. Tasks stay in your browser (`localStorage`).

## Run

```bash
npm install
npm run dev
```

## Features

- Add, edit, complete, and delete tasks
- Priority (high / medium / low) and optional due dates
- Filter by status, filter by priority, search, and sort
- Overdue and due-today labels
- Completion progress and clear-completed
- Deploy on AWS
- EC2->Docker Image->Docker Hub
